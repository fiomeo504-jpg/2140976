# Expense Tracker — Трекер расходов

**Автор:** Мигунова Ольга Евгеньевна

## Описание программы

GUI-приложение для отслеживания личных финансов. Позволяет вести учёт расходов, фильтровать записи и подсчитывать сумму за выбранный период.

### Функциональность:
- **Добавление расходов** (сумма, категория, дата)
- **Фильтрация** по категории и диапазону дат
- **Подсчёт суммы** расходов за произвольный период
- **Сохранение и загрузка** данных в JSON-файл
- **Удаление** записей
- **Автоматическая нумерация** записей (ID)

1. Убедитесь, что установлен Python 3.6+
2. Скачайте файл `expense_tracker.py`
3. Запустите в терминале:
   ```bash
