# 🌸 Random Task Generator

**Автор:** Мигунова Ольга Евгеньевна

## 📌 О проекте

**Random Task Generator** — это милое и функциональное приложение для генерации случайных задач. Программа поможет разнообразить ваш день, чередуя учёбу, спорт и работу, а также сохранит историю всех выполненных заданий.

### Основные возможности:
- 🎲 **Генерация случайной задачи** из готового списка
- 📝 **Добавление своей задачи** с выбором типа
- 🔍 **Фильтрация истории** по типу задач
- 💾 **Сохранение истории** в JSON файл
- 📂 **Автоматическая загрузка** при запуске
- 🗑 **Очистка истории** с подтверждением
- 📄 **Экспорт в CSV** для работы в Excel
- 📊 **Статистика** количества задач по типам
